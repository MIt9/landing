Shipped, not slideware

Real production outcomes, each framed as the problem, the fix, and the number that moved — with a walkthrough from the product portfolio channel.

Accessibility audit — the last mile is human

Problem
The automated a11y score plateaued while real screen-reader users still hit walls.
Solution
Three months validating directly with a blind user — fixed ARIA labels, focus traps, and live-region announcements in the header, cart, and search that audits couldn't catch.
Result
Audit score 60 → 95, plus a batch of real usability bugs closed.

Ship a blind link when there's no budget for the integration

Problem
A full third-party integration wasn't funded, so the obvious path was blocked.
Solution
Shipped a minimal "blind link" — the smallest thing that could route users through without the integration.
Result
Adoption moved from 0% to 10%.
